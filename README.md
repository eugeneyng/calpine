## Introduction

calpine is an open source front end for CalDAV. It's intended to interface with [Radicale](https://radicale.org) and [Baikal](https://sabre.io/baikal/). It was made because I didn't find there to be any good front-ends to the CalDAV servers.

## Contribute

Do you want to lend a hand? That’s great! We accept contributions from everyone, regardless of form.

Here are some of the things you can do to help.

### Contribute as a community

- Unlike Fight Club, the best way to help is **to actually talk about calpine** as much as you can in blog posts and articles, or on social media.
- You can answer questions in [the issue tracker](https://github.com/eugeneyng/calpine/issues) to help other community members.
- You can financially support calpine’s development [on Ko-Fi](https://ko-fi.com/eugeneng) or by subscribing to [a paid account]() (coming soon).

### Contribute as a developer

- Read our [Contribution Guide]() (coming soon).
- Install [the developer version locally]() (coming soon) so you can start contributing.
- Look for [issues labelled ‘Bugs’]() (coming soon) if you are looking to have an immediate impact on calpine.
- Look for [issues labelled ‘Help Wanted’]() (coming soon). These are issues that you can solve relatively easily.
- Look for [issues labelled ’Good First Issue’]() (coming soon). These issues are for people who want to contribute, but try to work on a small feature first.
- If you are an advanced developer, you can try to tackle [issues labelled ‘Feature Requests’]() (coming soon). These are harder to do and will require a lot of back-and-forth with the repository administrator to make sure we are going to the right direction with the product.

### Donate

You can support the development of calpine [on Ko-Fi](https://ko-fi.com/eugeneng). Thanks for your help.
